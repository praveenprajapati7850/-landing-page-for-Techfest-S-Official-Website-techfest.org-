## 🌌 Creative Direction & Concept

> **"THE FUTURE IS BEING REBUILT."**  
> *Science × Technology × Human Imagination × Competition × Innovation*

Designed as an editorial, high-contrast digital experience merging **NASA mission control telemetry**, **Renaissance astrolabes & sacred geometry**, and **IIT-level engineering rigor**.

- **Palette**: Charcoal and near-black canvas (`#05070b`), off-white typography, restrained electric cyan, deep cosmic violet undertones, and warm metallic gold accents.
- **2D / 2.5D Experience**: Interactive SVG astrolabe with concentric degree tracks, golden-ratio spirals, and mouse-reactive particle motes.
- **Atmospheric Telemetry**: Live countdown to Convocation Hall liftoff, IIT Bombay coordinates (`19.1334° N, 72.9133° E`), and an optional 174 Hz harmonic ambient soundscape.

1. **Cinematic Hero**:
   - Eyebrow: *IIT Bombay Presents*
   - Main headline: *TECHFEST 30* with visually dominant 30th-edition identity and Roman numeral `XXX`.
   - Thematic subtitle: *An Aetherial Renaissance*.

   - 4 Pillars of the 21st-century technological renaissance:
     - **Quantum Intellection**: Superconducting qubits and topological matter.
     - **Synthetic Cognition**: Agentic swarms and neuromorphic motor control.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation
```bash
# Clone or open the repository
npm install
```

### Development
```bash
npm run dev
```
Open `http://localhost:3000` to view the application.

### Production Build
```bash
npm run build
npm run start
```
